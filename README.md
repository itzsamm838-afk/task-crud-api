# Task CRUD API

A simple REST API built with Python and FastAPI for managing a to-do list.

The API supports the four main CRUD operations:

- Create tasks
- Read tasks
- Update tasks
- Delete tasks

The task data is stored in memory, so it resets whenever the server restarts.

## Tech Stack

- Python 3.10+
- FastAPI
- Uvicorn
- Pydantic
- Swagger UI / OpenAPI

## Features

- REST API endpoints
- In-memory task storage
- Request validation
- Proper HTTP status codes
- 404 handling for missing tasks
- Interactive Swagger UI documentation
